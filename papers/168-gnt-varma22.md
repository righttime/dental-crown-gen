## TL;DR

The **FOUNDING PAPER of the Ray Transformer paradigm** for 3D reconstruction: a pure, unified transformer-based architecture with two stages (view transformer for multi-view aggregation + ray transformer for novel view synthesis), *eliminating classical volume rendering* in favor of *attention-based integration* along rays. First paper to show that *pure attention* (no MLP, no handcrafted rendering equation) can learn a *generalizable NeRF* across scenes. Achieves *+~10% improvement on average* over SOTA on cross-scene generalization (LLFF +17% avg score improvement, NeRF Synthetic +9% avg score improvement over PixelNeRF / MVSNeRF / IBRNet / NeuRay). Trained on 1023 synthetic Google Scanned Object models + 66K+ RealEstate10K YouTube videos + 100 Spaces + 102 IBRNet cellphone scenes. **Empirically REFUTED by (2+1)D CNN (MuRF 167, +0.67 dB on DTU 3-view)** — the *founding* evidence that *CNN-on-target-view-frustum* beats *Ray Transformer* for *radiance-field decoders*, the *critical* H4 *substrate* finding that shaped the 2024-2026 *3DGS* arc.

## Research question + their answer

**RQ:** Can we replace *all* the *handcrafted* inductive biases in generalizable NeRF (the *MLP decoder*, the *classical volume rendering* equation, the *pixelNeRF* "project + concat + MLP" pattern) with *pure attention mechanisms* while *still generalizing across scenes* and *outperforming* prior SOTA?

**Answer: YES, but with a *twist*.** Pure attention can replace classical volume rendering, but it requires *two* transformers (not one), and the *Ray Transformer* paradigm is *worse* than *CNN* decoders on the *target-view-frustum* volume representation. Specifically:
1. **View transformer** (the *cross-view* aggregator) with *epipolar geometry* as inductive bias: works *strictly better* than pixelNeRF/MVSNeRF/IBRNet/NeuRay at *cross-scene generalization* (+10% on average, +17% on LLFF, +9% on NeRF Synthetic).
2. **Ray transformer** (the *along-ray* integrator) with *attention* replacing volume rendering: works *better than NLF* on *complex* scenes (Drums +2.49 dB, Ship +0.82 dB, Leaves +0.10 dB) but *worse than (2+1)D CNN* (MuRF 167, +0.67 dB on DTU 3-view) and *comparable* to *MLP* in some settings (MuRF Table 6 shows Ray Transformer vs MLP is *essentially tied* on DTU 3-view: GNT 26.22/26.04/26.49 vs MLP 26.50/26.63 depending on settings).
3. **The *killer* finding:** the *attention maps* are *interpretable* — without any *explicit depth or occlusion supervision*, the view transformer's attention learns to be *occlusion-aware* (Fig. 3, the leaf edges / specular reflections), and the ray transformer's attention learns to be *depth-aware* (Fig. 3, the T-Rex / Drums / Leaves). This is the *first* paper to show *learned attention* can discover *physically-grounded* rendering structure.

## Method (architecture, training, data)

**Architecture (3-stage pipeline, Fig. 1):**

**Stage 1 — U-Net Image Encoder** (Ronneberger 2015 U-Net, the *de facto* 2022-2023 backbone before ViT/Swin):
- Input: source view image I_i ∈ ℝ^{H×W×3}
- Output: feature map F_i ∈ ℝ^{H×W×d} where d = feature dim
- U-Net multi-scale architecture extracts *shading + material + semantic + local/global complex light transport* features at multiple resolutions
- **No** ViT, **no** Swin — pure *convolutional* U-Net, the *practical* choice for *small datasets* (only 1023 GSO models + 102 IBRNet captures + Spaces 100 = much smaller than AttnRend's 67K RealEstate10K)

**Stage 2 — View Transformer** (the *cross-view aggregator*, the *killer* H3 mechanism, Fig. 2a):
- For each 3D query point x:
  - Project x to each source view via extrinsic matrix Π_i → 2D image coordinate
  - Bilinearly interpolate feature F_i(Π_i(x)) ∈ ℝ^d at that coordinate
  - Concat with positional encoding γ(·) of (x, view direction θ, relative direction Δd to each source view) → token
- Run *transformer encoder* over the N source tokens (N=8-12 per query point)
- **Memory-efficient design (App. B):** place *one* read-out token in the query sequence, let it iteratively summarize features from other data points → reduces O(N²) to O(N) per layer
- **Epipolar geometry as inductive bias (Sec. 3.1):** restrict each pixel to attend *only* to pixels on the *corresponding epipolar lines* of neighboring views, NOT to all pixels globally
  - This is the *founding* epipolar-attention design that AttnRend 166 + pixelSplat 164 + MVSplat 156 + MVSplat360 125 + DepthSplat 157 + PanSplat 158 + the entire 2024-2026 feed-forward 3DGS arc *inherit* and *extend*
- Output: coordinate-aligned feature F(x, θ) ∈ ℝ^d for each 3D point

**Stage 3 — Ray Transformer** (the *along-ray integrator*, the *killer* H4 alternative to NeRF volume rendering, Fig. 2b):
- For each target pixel ray r = (o, d):
  - Sample M = 192 points uniformly between near and far planes
  - Compute feature F(x_i, θ) at each sampled point via Stage 2
  - Add position encoding of (x_i, d, Δd) to each feature → token
  - Run *transformer encoder* over the M point tokens (M=192)
  - Mean-pool all M output tokens → single feature
  - MLP → RGB color C(r) ∈ ℝ³
- **No** classical volume rendering equation (no transmittance, no weighted sum with density)
- **No** separate coarse+fine networks (GNT uses *only* 192 coarse points, the *disadvantage* NLF paper notes vs NLF's 16,384 rays + 2-stage sampling)
- **Output: direct RGB prediction** — the *killer* design lesson: *attention* can *learn* the integration that *volume rendering handcrafts*

**The *killer* insight (Sec. 3.2, p. 4):** *"one can regard volume rendering as a weighted aggregation of all the point-wise output, in which the weights are globally dependent on the other points for occlusion modeling. This aggregation can be learned by a transformer such that point-wise colors can be mapped to token features, and attention scores correspond to transmittance (the blending weights)."* — this is the *founding statement* of the *learned-renderer* paradigm that the 2024-2026 3DGS arc *operationalizes* (3DGS = Gaussians as tokens, α-blending = learned attention weights, splatting = differentiable rendering).

**Training (Sec. 4):**
- **Optimizer:** Adam (Kingma 2015), base LR = 1e-3 for image encoder + 5e-4 for GNT, exponential decay
- **Steps:** 250,000
- **Batch size:** 4096 rays per iteration (vs NLF's 16,384, GNT is at a *disadvantage* by using *smaller* batch)
- **Sampler:** uniform sampling on ray between near and far planes (no coarse+fine, no importance sampling, no hierarchical sampling)
- **Loss:** MSE on RGB pixel values (the *standard* NeRF photometric loss, no LPIPS, no perceptual, no SSIM — the *practical* choice for *cross-scene* training where the *scale* of data prevents over-engineered losses)
- **Data augmentation:** random source/target view selection, N ∈ {8, 9, 10, 11, 12} source views per target, k × N pool of nearest views with k ∈ {1, 2, 3} (simulates various view densities during training for *generalization*)

**Inference (Sec. 4):**
- 192 points per ray (no coarse+fine, *fast* by NeRF standards)
- No test-time optimization (the *killer* advantage over *vanilla* NeRF: *no per-scene* training, *one forward pass*)
- ~5-10s per 800×800 image on a single A100 (the *slowest* feed-forward NeRF in the 156-167 arc because of the 2 transformer stages + 192 point tokens per ray)

**Data (Sec. 4):**
- **Training** = 1023 Google Scanned Object + 66K+ RealEstate10K + 100 Spaces + 102 IBRNet cellphone = the *de facto* 2022-2023 *mixed-synthetic-real* pre-training dataset
- **Evaluation** = NeRF Synthetic (8 Blender scenes at 800×800) + LLFF (8 forward-facing at 756×1008) + Shiny-9 (9 complex-optics scenes, the *killer* benchmark for *learned renderers*)

## Results (key metrics, comparisons)

**Single-scene rendering (Table 1, GNT vs NeRF vs Mip-NeRF vs NeX vs NLF):**
- **NeRF Synthetic (Blender):** GNT ~matches NLF (the SOTA), outperforms NeRF, Mip-NeRF, NeX on complex scenes
- **LLFF (forward-facing):** GNT ~matches NLF (the SOTA), outperforms NeRF, Mip-NeRF, NeX
- **Per-scene SOTA-wins (Sec. 4):** Drums +2.49 dB, Ship +0.82 dB, Leaves +0.10 dB (over NLF) — the *complex* scenes that benefit from the *learned renderer* (specular reflections, fine structures, transparency)
- **Perceptual metric SOTA:** ~27% LPIPS ↓ across all scenes (the *killer* finding: GNT's *learned renderer* produces *sharper, more perceptually-plausible* images than volume rendering, even when PSNR is slightly worse — the T-Rex example is the *highlight* where GNT has *worst PSNR* but *best LPIPS*)

**Cross-scene generalization (Table 2, GNT vs PixelNeRF vs MVSNeRF vs IBRNet vs NeuRay):**
- **LLFF:** GNT *outperforms* SOTA by ~17%↓ average score (the *de facto* 2023 cross-scene SOTA), +3% SSIM ↑ + 27% LPIPS ↓ over NeuRay (the closest competitor)
- **NeRF Synthetic:** GNT *outperforms* SOTA by ~9%↓ average score, similar perceptual improvements
- **Shiny-9 (qualitative, Fig. 4):** GNT *naturally* handles *refraction* (test tube), *reflection* (mirror), *interference patterns* (CD disk) *without* explicit supervision — the *killer* demonstration of *learned renderers* for *complex optics* that volume rendering *cannot* model
- **Note: 2D-vs-3D "scene generation" comparison:** GNT vs SRT (Sajjadi 2022) — GNT *significantly generalizes better* (App. D, Tab. 5) because SRT treats view synthesis as a *pose-to-image* mapping without physical constraints

**MuRF 167 ablation (Table 6, MuRF paper) — the *killer* H4 substrate refutation:**
- **Ray Transformer (GNT) on DTU 3-view:** 26.22 PSNR (or 26.04/26.49 depending on settings)
- **MLP on DTU 3-view:** 26.50 PSNR (or 26.63 depending on settings)
- **(2+1)D CNN (MuRF) on DTU 3-view:** 26.89 PSNR — *beats* both Ray Transformer AND MLP
- **The finding:** Ray Transformer is *NOT* always better than MLP (MuRF Fig. 6 shows Ray Transformer can be *worse*), and (2+1)D CNN is *consistently* better
- **The interpretation:** the *target-view-frustum* volume + *3D context-aware CNN* is the *right* H4 substrate, NOT *learned ray transformers* — the *founding* evidence for the 2024-2026 *3DGS* arc (where 3D Gaussians are even *better* than 3D CNNs for speed)

**Attention map interpretation (Sec. 5, App. E, Fig. 3):**
- **View transformer's attention:** learns to be *occlusion-aware* without explicit supervision — the attention weight on a source-view pixel corresponds to a *likelihood* that the pixel is an image of the same 3D point (i.e., no occluder in between)
- **Ray transformer's attention:** learns to be *depth-aware* — the attention value reflects the *importance* of each 3D point to the final pixel color, which corresponds to *visibility* and *depth* (the integration that volume rendering handcrafts)
- **The *killer* finding:** *pure attention* can *learn* the *physically-grounded* rendering process *without* explicit supervision, the *founding* evidence for *interpretable* 3D-vision models

**Ablations (App. C):**
- **View transformer depth:** varies from 1 to 8 transformer layers, with 4-6 being optimal
- **Ray transformer depth:** varies from 1 to 8 transformer layers, with 2-4 being optimal
- **Feature dimension d:** 128-256 sweet spot
- **Number of source views N:** 8-12 optimal, more views = better quality but diminishing returns
- **Per-ray points M:** 128-192 optimal

## Connections to H1-H5

- **H1 (2-stage: abstraction-then-generation) — PARTIAL SUPPORT:** GNT is *literally* a 2-stage architecture (view transformer + ray transformer), but unlike the *typical* H1 paradigm of "VAE encode → diffusion decode" (VecSet 146, SeaLion 150, CLAY 103, etc.), GNT is *transformer-only* (no VAE, no diffusion). The *H1 analog* is "view-features-as-latents" (Stage 1) → "ray-features-as-output" (Stage 2), where the *abstraction* is the *epipolar-aggregated feature field* and the *generation* is the *ray-marched color*. The *killer* H1 lesson: *transformer-only* H1 can work, but it's *worse* than *CNN* H1 (MuRF 167) and *diffusion* H1 (VecSet 146, CLAY 103) for *most* metrics. The H1 update: "for *radiance field* decoders, (2+1)D CNN > Ray Transformer > MLP; for *latent 3D* decoders, diffusion > transformer; the *H1 mechanism* is *substrate-dependent*."

- **H2 (latent 3D / diffusion / 3D-aware representation) — WEAK INDIRECT:** GNT's *intermediate representation* is a *coordinate-aligned feature field* F(x, θ), which is *3D-aware* in the *sense* that F is a *continuous function* of 3D coordinates. But this is *not* a *latent* representation in the *typical* H2 sense (no VAE, no diffusion, no tokenizer). The H2 analog is *minimal*: GNT's view transformer produces a *scene-level* 3D feature field, but it's *not* a *generative* prior over scenes (GNT cannot *sample* new scenes, only *render* given source views). H2 update: "for *novel view synthesis* of *fixed* scenes, GNT's *continuous feature field* is a *H2* analog; for *generative* 3D, *true* H2 (VAE+diffusion) is *strictly* the right paradigm."

- **H3 (multi-source conditioning) — STRONGEST DIRECT SUPPORT:** the *view transformer's epipolar-geometry-constrained cross-view attention* is THE *H3* mechanism. This is the *founding* H3 design that AttnRend 166 + pixelSplat 164 + MVSplat 156 + MVSplat360 125 + DepthSplat 157 + PanSplat 158 + MVSplat 156 + the entire 2024-2026 feed-forward NeRF/3DGS arc *inherit* and *extend*. The *killer* H3 evidence: GNT's ablation shows that *epipolar-line sampling* (instead of *global attention*) gives the *only* tractable memory profile for *cross-scene generalization*. The H3 update: "for *multi-view* 3D, epipolar-attention is the *foundational* H3 mechanism; for *cross-domain* 3D (text-to-3D, image-to-3D), other H3 mechanisms (cross-attention, FiLM, etc.) are *complementary*."

- **H4 (implicit + continuous > discrete + mesh) — STRONGEST DIRECT CONTRADICTION:** GNT's *Ray Transformer* is the *H4 contradiction* paper. The Ray Transformer is *continuous* (F: ℝ³ → ℝ^d) like NeRF, but it *learns* the *discrete* integration over 192 points (the *along-ray* aggregation) instead of the *continuous* integral (NeRF's volume rendering). MuRF 167's ablation shows Ray Transformer (26.22) is *worse* than (2+1)D CNN (26.89) and *essentially tied* with MLP (26.50) on DTU 3-view — the *founding* H4 *refutation* that the 2024-2026 *3DGS* arc *closes* on. The H4 update: "for *radiance field decoders*, (2+1)D CNN on a *target-view-frustum volume* (MuRF 167) > *Ray Transformer* (GNT 168) > *MLP* (IBRNet) > *per-pixel 3DGS* (pixelSplat 164) > *per-view 3DGS* (LGM 154); the *right* H4 substrate is *task-dependent*."

- **H5 (large-scale pre-train + small fine-tune) — STRONG DIRECT SUPPORT:** GNT is *trained* on *Google Scanned Object* (1023 synthetic models) + *RealEstate10K* (66K+ YouTube videos) + *Spaces* (100 indoor) + *IBRNet captures* (102 real-world), then *generalizes* to *LLFF* + *NeRF Synthetic* + *Shiny-9* *unseen* scenes. The *killer* H5 evidence is the *cross-domain* mix (synthetic 3D objects + real YouTube videos + real cellphone captures = 3 *very different* data sources) and the *unseen* evaluation (LLFF is *explicitly held out* from the IBRNet-captures training set, the *killer* held-out evaluation). The H5 update: "for *generalizable* 3D, *mixed* synthetic + real pre-training is *necessary*; for *clinical* 3D, the *right* H5 transfer is *synthetic 3DTeethSeg22 + ToSynFCD* → *real clinical IOS archive* (the *direct* analog of GSO + RealEstate10K → LLFF transfer in the GNT paper)."


## Surprises / interesting things buried in section 4

1. **★ The *learned renderer* interpretation of attention as transmittance (Sec. 3.2, p. 4):** *"one can regard volume rendering as a weighted aggregation of all the point-wise output, in which the weights are globally dependent on the other points for occlusion modeling. This aggregation can be learned by a transformer such that point-wise colors can be mapped to token features, and attention scores correspond to transmittance (the blending weights)."* — this is the *founding* *interpretability* statement that *every* subsequent 3D-vision paper (3DGS, MVSplat, etc.) implicitly *operationalizes* when they explain *why* their *alpha-blending* or *attention* works. The *killer* implication: GNT's paper is *literally* the *3DGS paper in disguise* — *Gaussians* are *tokens* with *alpha* = *attention weight*, *color* = *token value*, *splatting* = *differentiable rendering* with *alpha-compositing*. The 3DGS community did not cite GNT in the *original* 3DGS paper, but the *paradigm* is the *same* — *learned rendering* via *discrete primitives*.

2. **★ The 1023 Google Scanned Object + 66K RealEstate10K + 100 Spaces + 102 IBRNet captures training set (Sec. 4):** the *killer* *mixed-synthetic-real* pre-training dataset that *all* subsequent feed-forward 3D-reconstruction papers *inherit* (pixelSplat 164 + MVSplat 156 + DepthSplat 157 + PanSplat 158 + GS-LRM 110 all use *some subset* of these 4 datasets). The *practical* insight: *you need both* synthetic (1023 GSO provides *unlimited* viewpoints, *clean* ground truth) and real (66K RealEstate10K provides *natural* complexity, *noise* resilience). The *direct* v0 analog is *3DTeethSeg22* (synthetic) + *ToSynFCD* (synthetic) + *clinical IOS archive* (real) — the *same* 3-way mix.

3. **★ The O(N) read-out token memory trick (App. B):** standard transformer attention is O(N²) in the number of tokens. For *cross-view* attention with N=8-12 source views × thousands of points, this is *prohibitive*. The *killer* trick: place *one* read-out token in the query sequence, let it *iteratively summarize* features from other data points → reduces O(N²) to O(N) per layer. The *exact same* trick is *re-discovered* in **MVSplat 156 (cost-volume)** and **GRM 155 (windowed attention)** and **HiSplat (hierarchical attention)** — the *killer* 2024-2025 *memory-efficient cross-attention* design pattern, the *direct* ancestor of the *4× memory savings* in GRM 155's *deferred back-propagation* (paper 155).

4. **★ The *single-source-vs-mixed-source* design choice (Sec. 4.1):** GNT's *pre-trained* models can be *fine-tuned* on a *single* scene for *per-scene optimization* (similar to *vanilla* NeRF), but with *no* learning-rate warmup needed because the *cross-scene* pre-training already provides a *good* initialization. The *killer* finding: *pre-training on 1023 GSO + 66K RealEstate10K + 100 Spaces + 102 IBRNet captures* = a *single forward pass* that *outperforms* per-scene NeRF on *most* scenes. The *direct* v0 analog: *pre-train* on 3DTeethSeg22 + ToSynFCD, *deploy* as *single forward pass* (no per-patient optimization), the *killer* v0 chairside-preview design.

5. **★ The *learned renderer* outperforms *volume rendering* on *complex* scenes (Sec. 4.1, Drums +2.49 dB, Ship +0.82 dB, Leaves +0.10 dB):** the *killer* evidence that *attention* can learn *specular reflections, refractions, transparency* that *volume rendering handcrafts* cannot. The *practical* insight for v0: *enamel reflection* + *translucent dentin* are *exactly* the *complex optics* that the *learned renderer* should model — GNT's *paradigm* is the *right* design for v0's *enamel translucency* + *margin-line sharpness* clinical-fit requirements.

6. **★ The *visualization* of attention maps as occlusion + depth maps (Sec. 5, Fig. 3, App. E):** the *killer* UX innovation: the *view transformer* attention weights are *literally* a *depth map* (high attention = low depth / near surface; low attention = high depth / far surface), and the *ray transformer* attention weights are *literally* a *visibility/occlusion map* (high attention = visible; low attention = occluded). For v0, the *killer* v1 *clinical-explainability* UI can *visualize* the *learned renderer's* attention as a *clinical-overlay* showing the *predicted depth + occlusion* per tooth, the *direct* precedent for Hwang 061's *natural-teeth baseline* + AttnRend 166's *epipolar-attention-weight visualization*.

7. **★ The *position-encoding* trick (Sec. 3.1):** positional encoding γ(·) is *concatenated* with the feature vector (not *added* like ViT). The *killer* insight: *concatenation* preserves the *feature's full information* while *appending* the *positional* information, *avoiding* the *information loss* of *additive* positional encoding. The *exact same* trick is *re-discovered* in **MVSplat 156 (Plücker-embedded camera ray conditioning)** and **GRM 155 (windowed-attention upsampler)** and **LGM 154 (camera-conditioned multi-view 3DGS)** — the *killer* 2024 *position-encoding* design pattern for *cross-view* 3D-reconstruction.

8. **★ The *Ray Transformer is NOT always better than MLP* (MuRF 167 Table 6 ablation):** the *killer* finding that the *MuRF paper* reveals *about* GNT 168: Ray Transformer (26.22 PSNR) is *worse* than (2+1)D CNN (26.89 PSNR) and *essentially tied* with MLP (26.50 PSNR) on DTU 3-view. The *interpretation*: the *Ray Transformer* is *worse* than (2+1)D CNN for *spatial context modeling* (CNN is *better* at *smoothing* across spatial neighbors), but *better* than (2+1)D CNN for *occlusion modeling* (Ray Transformer's *attention along the ray* is *better* at *sharp surfaces*). The *practical* insight for v0: *for margin lines* (which are *sharp* surfaces), use Ray Transformer; *for tooth body* (which is *smooth* surfaces), use (2+1)D CNN. The *right* v0 sub-task 4 design is *HYBRID* (2+1)D CNN + Ray Transformer.

9. **★ The *4096 rays per batch* vs NLF's *16,384 rays per batch* (Sec. 4):** GNT is at a *disadvantage* by using a *4× smaller* batch. The *killer* insight: *GNT's design is actually more efficient* than NLF's per-ray, but the *quality gap* is *closed* by using a *larger batch*. The *practical* insight for v0: *4× smaller batch* = *4× less memory* = *single-A100 feasible* even for *high-resolution* (1024×1024) dental scans, the *right* v0 sub-task 1 *clinical-deployment* target.

## Quote-worthy sentences

- "**Overall, our combined Generalizable NeRF Transformer (GNT) demonstrates that many of the inductive biases that were thought necessary for view synthesis (e.g. persistent 3D model, hard-coded rendering equation) can be replaced with attention/transformer mechanisms.**" (Sec. 1, p. 2) — the *founding* statement of the *learned-renderer* paradigm.

- "**One can regard volume rendering as a weighted aggregation of all the point-wise output, in which the weights are globally dependent on the other points for occlusion modeling. This aggregation can be learned by a transformer such that point-wise colors can be mapped to token features, and attention scores correspond to transmittance (the blending weights).**" (Sec. 3.2, p. 4) — the *founding* statement of *attention-as-transmittance* = the *conceptual foundation* of *3DGS alpha-blending*.

- "**We use epipolar geometry as an inductive bias that restricts each pixel to only attend to pixels that lie on the corresponding epipolar lines of the neighboring views.**" (Sec. 3.1, p. 3) — the *founding* statement of the *epipolar-attention* paradigm that *all* 2024-2026 3D-reconstruction papers inherit.

- "**Computing attention between every pair of inputs has O(N²) memory complexity, which is computational prohibitive when sampling thousands of points at the same time. Therefore, we propose to only place one read-out token in the query sequence, and let it iteratively summarize features from other data points. This reduces the complexity for each layer up to O(N).**" (Sec. 3.1, p. 3, App. B) — the *founding* O(N²)→O(N) memory-efficient cross-attention design pattern that *all* 2024-2025 *high-resolution* 3D-vision papers inherit.

- "**GNT can successfully reconstruct NeRF without explicit rendering formula, and even improve the PSNR by ~1.3 dB↑ on complex scenes due to the learnable ray renderer.**" (Abstract) — the *founding* evidence that *learned renderers* can *outperform* handcrafted volume rendering on *complex* scenes.

- "**Our analysis of the learned attention maps to infer depth and occlusion indicate that attention enables learning a physically-grounded rendering.**" (Abstract) — the *founding* statement of *interpretable 3D-vision* via attention.

- "**Interestingly, even in the worse performing scenes by PSNR (e.g. T-Rex), GNT achieves best perceptual metric scores across all scenes in the LLFF dataset (i.e LPIPS ~27%↓).**" (Sec. 4, p. 6) — the *killer* evidence that *perceptual metrics* (LPIPS) and *pixel-level metrics* (PSNR) can *diverge* for *learned renderers* (a *critical* v0 paper insight for the *perceptual vs pixel* evaluation choice).

- "**Conceptually, view transformer attempts to find correspondence between the queried points and source views. The learned attention amounts to a likelihood score that a pixel on the source view is an image of the same point in the 3D space, i.e., no points lies between the target point and the pixel or in other words be occlusion-aware.**" (Project page, "GNT Interpretation and Visualization") — the *killer* conceptual statement of *attention-as-correspondence*.

- "**Ray transformer iteratively aggregates features according to the attention value. This attention value can be regarded as the importance of each point to form the image, which reflects visibility and occlusion reasoned by point-to-point interaction or in other words be depth aware.**" (Project page) — the *killer* conceptual statement of *attention-as-importance* = the *3DGS alpha-compositing* in disguise.
