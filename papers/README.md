## Seed list (initial)

### Tooth segmentation / dental 3D
- 3DTeethSeg: http://www.3dteethseg.com/

- MeshSegNet: https://github.com/TaiXiangDu/IAFA

- 3D-Diffusion (Wu et al., 2023)
- SDF-Diffusion
- Point-Voxel Diffusion
- MeshDiffusion
- PolyGen (DeepMind)
- MeshGPT (Autodesk)

### Point cloud completion (relevant for partial scans)
- PCN (Yuan et al., 2018)
- PoinTr (Yu et al., 2021)
- SnowflakeNet
- Seedformer

### Neural implicit surfaces
- DeepSDF (Park et al., 2019)
- Occupancy Networks
- ConvONet
- DiGS (divergence-guided shape implicit)

### Dental CAD / commercial
- 3Shape, exocad (closed-source — study output)
- Datasets: Tufts, OSF dental scans

### Evaluation
- Chamfer distance, Hausdorff distance
- IoU/Dice for segmentation
- Clinical fit metrics (margin gap, internal fit)
