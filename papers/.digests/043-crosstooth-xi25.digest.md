## TL;DR

**CrossTooth is the first paper in our reading list to explicitly attack the crown–gingiva boundary problem with a two-headed design: (1) geometric pre-processing — selective downsampling (a QEM extension that uses mean curvature to set the edge-collapse weight `k`, with `k=10` for negative-curvature edges at tooth boundaries and `k=1` for positive-curvature edges at cusp tips, preserving 10-15% more boundary vertices than vanilla QEM); and (2) cross-modal H3 — render 96 multi-view images of the IOS under a vertical downward parallel light, extract dense boundary features with PSPNet, then project the per-view image features back onto the point cloud via camera parameters, fusing dense image features with sparse point features before the final MLP head.** Boundary supervision comes from a Contrastive Boundary Learning (CBL) loss (InfoNCE-style, last decoder layer only) that pulls same-class neighbors together and pushes different-class neighbors apart. On 3DTeethSeg'22 (1440/360 split, non-canonical) CrossTooth hits **95.860% mIoU and 82.058% Boundary IoU** beating ToothGroupNet by +2.314 mIoU and **+5.666 B-IoU**; on 3D-IOSSeg 86.11% mIoU / 65.30% B-IoU with only 5.05G FLOPs (10-20× cheaper than second-tier methods). The +5.7 absolute B-IoU gain is the clinically important one (margin-line accuracy) and is the largest 1st-vs-2nd gap in the table.

## Hypothesis connections

- **H1 (2-stage > 1-stage):** NO RELEVANT EVIDENCE. CrossTooth is 1-stage supervised (no SSL, no DDM, no VAE); the simplest possible encoder→decoder→MLP head with cross-modal fusion at the end. Consistent with H1-revised-from-042: **H1 is generation-specific, segmentation is 1-stage-only**. Pattern now firm for v0 sub-task 1: 1-stage supervised + pre-processing + cross-modal features + boundary-aware loss. No 2-stage VAE+DDM for segmentation.
- **H2 (latent diffusion > direct):** NO RELEVANT EVIDENCE. Deterministic encoder-decoder; image features concatenated (not diffused); CBL contrastive (not diffusion). H2 generation-specific. For v0 sub-task 4, **port the boundary-aware-loss principle to crown generation**: add a margin-line preservation loss that penalizes the diffusion model for deviating from the input prep margin (analog of CBL for crown gen).
- **H3 (conditioning on adjacent+opposing teeth):** ★★ **STRONG SUPPORT via cross-modal image features (NOVEL in reading list).** 96 multi-view images capture what the point cloud *cannot* see — subtle color/shading transitions at the tooth-gingiva boundary invisible to a 3D modality with only coordinates+normals. Image features projected back onto the point cloud via camera parameters become a *form of H3 conditioning*. **The cleanest cross-modal H3 mechanism in the entire reading list** — orthogonal to LION's latent H3, AnchorFormer's anchor H3, and AdaGN. Free +0.74% mIoU / +0.49% B-IoU.
- **H4 (implicit SDF > explicit mesh):** **REFINED.** CrossTooth operates on point clouds + original mesh topology; selective downsampling preserves the mesh (QEM extension) but the network consumes *points sampled from the mesh*. Opposite to H4 for segmentation. **H4 REFUSED at sub-task 1 (point cloud + selective downsampling), CONFIRMED at sub-task 4 (SDF for crown gen).** v0 stack unchanged: sub-task 1 = point cloud (STEAM-style SSL on selectively-downsampled input) + cross-modal image features; sub-task 4 = point cloud → SDF (DiGS 003) → mesh (FlexiCubes 007).
- **H5 (synthetic pretrain + light fine-tune generalizes to real):** ★★ **STRONG SUPPORT (cross-dataset).** Same architecture + recipe generalizes to two different dental datasets (3DTeethSeg'22 France/Tunisia/US + 3D-IOSSeg Chinese clinical scanners); **selective downsampling trick transfers cleanly** (Table 5: SD improves *every* method on *every* dataset, +1.4-7.4 B-IoU points). Cross-dataset validation is a *stronger* H5 than synthetic-to-real because it tests the architectural inductive bias (curvature-aware pre-processing) rather than the pretraining corpus. **For v0: selective downsampling is a universal pre-processing upgrade, not a dataset-specific trick — adopt for the 4,200-scan combined corpus.**
