## TL;DR

**Point2SSM++ is the self-supervised + multi-anatomy + 4D extension of Point2SSM (paper 039)** — same DGCNN-encoder + SFA-attention + CD+ME-loss core, augmented with (1) **self-supervised pre-training** via MPointR (BERT-style masked point reconstruction on 5000+ unlabeled shapes, 3-5× faster convergence), (2) **downstream classifier head** that turns SSM into multi-anatomy identifier (one model for spleen/pancreas/atrium/vertebrae/tooth-arch), (3) **4D spatiotemporal extension** via PSTNet2 (Fan et al. 2021b) producing (M, T, 3) correspondence trajectories, and (4) **theoretical IB justification** showing the architecture is an *implicit* Information Bottleneck implementation (kNN K = compression, feature L = bottleneck capacity, attention = expressiveness, CD loss = implicit IB objective). Killer empirical property: **robustness to misaligned/inconsistent input** — worst-case combined corruption (15° rot + 20mm trans + 30% drop): Point2SSM++ CD 4.3 vs v1 CD 9.1 (109% improvement), and Point2SSM++ on worst-case is STILL better than Point2SSM v1 on clean input. Closes the SSM reading arc (037 ToothForge → 038 SAE-LP → 039 Point2SSM → 040 Point2SSM++).

## Hypothesis connections

- **H1 (2-stage > 1-stage):** NO RELEVANT EVIDENCE. Point2SSM++ is 1-stage (encoder+attention), no VAE, no DDM. Consistent with SSM-vs-generation distinction: SSM is *deterministic correspondence* (one input → one canonical frame), generation is *stochastic sampling* (one input → many valid outputs). Not directly comparable on H1.
- **H2 (latent diffusion > direct):** NO RELEVANT EVIDENCE. No diffusion, no VAE. Architectural echo: per-point SFA attention ≈ LION's (005) per-point AdaGN conditioning. Cleanest H2 counter-example: for deterministic correspondence the 1-stage direct loss beats 2-stage DDM (no distribution to sample from). For us: sub-task 4 needs multi-modal crown generation → H2 holds (LION > Point2SSM++); sub-task 1 per-arch SSM → 1-stage direct (Point2SSM++) is right.
- **H3 (global arch context > local):** ★★★ **STRONGEST SUPPORT YET (for SSM tasks).** Three independent H3 mechanisms in one paper: (a) **global anatomy conditioning** via multi-anatomy classifier head (model knows which tooth type before extracting correspondence landmarks), (b) **local neighborhood conditioning** via kNN graph + SFA attention (per-point features encode K-nearest neighbors → mesial/distal adjacent teeth in receptive field), (c) **temporal conditioning** via 4D PSTNet2 (each time slice conditioned on previous slice → prep evolution t=0→t=1→t=2 smoothly tracked). Direct sub-task 1 implication: multi-anatomy variant is "tooth-class-aware correspondence model" — more anatomically grounded than point-wise segmentation (MeshSegNet 023 / TSegNet 027).
- **H4 (implicit SDF > explicit mesh):** MILD REFINEMENT. Point cloud not SDF. But IB-theoretic justification relevant: kNN graph + L-dim bottleneck is mathematically equivalent to *local implicit surface parameterization* (IB-optimal Z is minimal sufficient statistic of X for predicting Y = SSM coordinate system). For v0: IB theory gives principled way to COMPARE SSM (Point2SSM++) vs implicit-SDF (DiGS 003) — pick lower Pareto frontier. Hypothesis: for *correspondence* point-cloud SSM wins; for *reconstruction* implicit-SDF wins. For sub-task 4 need BOTH.
- **H5 (synthetic pretrain + light fine-tune generalizes to real):** STRONG SUPPORT. (i) Self-supervised pre-training IS the H5 mechanism (3-5× convergence speedup + 0.5-1.5% CD are direct evidence), (ii) Multi-anatomy robustness is IMPLICIT H5 (training on 4 anatomies regularizes encoder to learn general features that transfer to unseen anatomies, 12% better than Point2SSM v1 on lung/kidney), (iii) Robustness to misaligned input is PRACTICAL H5 (109% improvement on combined corruption means model works on real data without manual preprocessing). STRONGEST H5 EVIDENCE STACK in SSM reading arc and CLEANEST H5 EVIDENCE across all 40 papers.
